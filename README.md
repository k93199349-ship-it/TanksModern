# TanksModern

Танковая 3D-игра в стиле Tanki Blitz в одном файле `index.html` (Three.js, без сборки):
3D-ангар, ветки прокачки (Германия, СССР), магазин с контейнерами/хранилищем/акциями,
бой 6×6 на большой карте с растительностью и руинами, физика, панель снарядов,
управляемые ракеты ПТУР, мобильное управление (ландшафт).

## Запуск

Открыть `index.html` в свежем Chrome/Edge/Firefox (нужен интернет для загрузки Three.js).
На телефоне — открыть по HTTPS/локальной сети в альбомной ориентации.

## Атрибуция ассетов
